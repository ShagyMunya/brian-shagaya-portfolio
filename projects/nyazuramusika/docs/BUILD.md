# Build and verification

The Android APK was built successfully by the **Build NyazuraMusika Android** workflow. Price and international-contact-number unit tests passed. The service passed 55 isolated integration checks covering PKCE, single-use codes, session revocation, profile validation, photo ownership, listing ownership, exact prices, filters, pagination, sold and removed states, body limits, rate limiting and unavailable storage.

The shared service is deployed as an owner-private preview. Activating public access is required for the Android app to reach the service as local buyers and sellers. The complete browser-to-Android ChatGPT sign-in return and the screens should still be tested on a physical Android device before opening the market.
